# 表形式の一括入力の検証

2026-10-15。既存のCSV・TSV・JSON・URLリスト入力に加え、共通GUIに表形式の入力方法を追加した。

## 仕様

- 一括入力の「入力方法」でテキスト／表形式を選択する。切り替えても各方式の入力内容を保持する。
- 絵文字名・画像URL・カテゴリーの3列。初期状態は3行で、行を追加・削除できる。行操作後は隣接行または追加した行の名前欄にフォーカスする。
- 完全な空行を読み飛ばし、空のカテゴリーには既定値を適用する。名前の正規化、URL、安全性、重複、件数、パックサイズには既存の制限を適用する。
- 入力不備や重複がある場合は全体の追加を中止し、入力を保持する。空行を除いた後もエラーは元の表示行番号を示す。
- テーブル内で横スクロールできる。22言語とRTLに対応し、Web版とMOD版で同じコンポーネントを使用する。
