# Nextcloudの名前衝突と表の問題行表示

2026-10-17。利用者が提供したXMLから再現条件を抽出した。外部サイトへの接続や画像のダウンロードは行っていない。

## 原因と動作

- XMLは430応答（共有フォルダー自身1件、画像429件）。`medetai-nya.gif` と `medetai-nya.png` は別ファイルだが、従来は拡張子を除いて同じ名前を生成していた。日本語を含む10ファイルも、使用できる文字への変換後に `nya` で衝突していた。
- 名前が衝突するNextcloud画像は、拡張子と必要に応じた連番で区別する。既存の自然なファイル名を予約し、64文字制限を保つ。画像URL・順序・カテゴリーを保持する。
- 表は入力中から名前の重複、既存パックとの同名、入力不備を検出する。重複する全行を太字・背景色で示し、該当欄に理由と重複相手の行番号を表示する。問題行の件数と順次移動ボタンを設け、修正時に表示を更新する。
- 空行は従来どおり読み飛ばす。追加時の検証は維持し、不備のある入力を部分追加しない。
- 独立レビューで見つかった共通URLの残留も修正した。パックを新規作成・切り替えした際は前の共有URLをクリアする。

## RED → GREEN
