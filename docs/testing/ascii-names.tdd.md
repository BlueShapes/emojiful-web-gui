# 非ASCII絵文字名を登録前に拒否する

2026-10-17。利用者の要望から、非対応文字を含む絵文字名は注意ではなく修正必須のエラーとした。

## 原因と修正

保存時の名前検証は既に日本語などを拒否していたが、個別編集には入力中のエラー表示がなく、置換プレビューは置換対象外の不正な名前を無視していた。また、小文字化で `K` が `k` になることや、全角空白・ノーブレークスペースが汎用トリムで消えることによる見落としがあった。

- 名前の正規化はASCII空白の除去・前後の `:` の除去・ASCII大文字の小文字化に限定する。検証では汎用トリムより前に非ASCII文字を拒否する。CSV入力全体のトリムでも最初の名前の非ASCII空白を消さない。
- 日本語・半角カナ・全角英数字・アクセント文字・絵文字・非ASCII空白を含む名前を拒否する。使用可能なASCIIの `_`・`-` と、日本語のカテゴリー・画像URLを維持する。
- 個別編集で入力中に赤い説明と `aria-invalid` を表示し、登録・保存ボタンを無効にする。修正するとエラーが消え、登録できる。
- 表の名前が不正な場合は文字数だけの注意を重ねず、エラーとして表示する。一括追加は引き続き原子的に拒否する。
- 一括置換では変更しない名前も含めて検証し、不正な名前が残る間は適用できない。未変更の文字列自体は書き換えない。日本語名をASCII名へ一括置換して修正できる。
