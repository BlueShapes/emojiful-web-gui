# 複数パックとサイドバーの検証記録

2026-10-15。ユーザーの「複数パックを作成し、折りたたみ可能なサイドバーと簡単な切り替えを使いたい」という依頼から、以下の操作と保証を定義した。

- 以前の1パック分の下書きを、未完成の名前・IDを含めて引き継ぐ。
- 複数パックを独立して作成・編集・切り替え・削除する。ファイルや配置済みパックの読み込みは既存の下書きを保持して追加する。
- 折りたたみ状態と選択中のパックを、再読み込みと言語変更後も復元する。
- 破損した保存データを自動保存で上書きせず、容量不足などの保存失敗をサイドバーが閉じていても表示する。
