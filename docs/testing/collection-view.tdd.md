# コレクションの並び替えと表示切り替え

2026-10-17。追加した絵文字を見やすく整理するため、コレクションに表示形式と並び順の選択を追加した。

## 仕様

- 表示は既存のカード、詳細を横に並べるリスト、小さな画像・名前・操作ボタンをまとめるコンパクトの3種類。
- 並び順は追加順の昇順／降順、名前の昇順／降順、カテゴリーの昇順／降順、名前の短い順／長い順、エラー・注意優先の9種類。初期値はカード・追加順（古い順）。
- 名前とカテゴリーは画面の言語に沿って比較し、数字を自然な順番で扱う。同じカテゴリーや同じ長さは名前の昇順で、名前の自然順比較でも同じになる項目は元の順序を保つ。
- エラー・注意優先は標準名との衝突、現在の注意基準以上の長い名前、通常の名前の順。同じ優先度内は元の順序を維持する。
- 検索・カテゴリー・注意の絞り込み後の配列を表示用に並び替え、ワークスペースやパックの元の順序を変更しない。表示を変えても個別編集・削除の対象は名前で識別し続ける。
- 表示形式・並び順は独立したブラウザー設定に保存し、復元完了前に初期値で上書きしない。不正なJSONや未知の設定値には項目ごとの初期値を使う。保存が利用できない場合も画面を操作でき、ワークスペースの保存を妨げない。
- 表示を変えても、エラー・注意の全文と編集・削除ボタンを維持する。コンパクトではカテゴリー・URLを省略する。日本語とアラビア語、モバイルと狭いデスクトップで折り返し・収まりを確認する。
- 14個の操作ラベルを22言語に追加した。ブラウザー設定の保存以外の外部通信を追加していない。
